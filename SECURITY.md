# Security

Please don't open a public issue for a security problem. Report it privately instead: the Security tab, then "Report a vulnerability".

Only the latest release gets fixes. They come out as a patch release and are listed in the [CHANGELOG](CHANGELOG.md). This is a personal project, so there's no set response time, but security reports come first.

Problems in the installed system, rather than the installer, belong to [ephemeral-nixos-config](https://github.com/the-wittch/ephemeral-nixos-config/security).
